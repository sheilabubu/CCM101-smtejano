# Cloud Infrastructure Components

## 1. Compute Resources

**Example:** Intel Xeon E312xx CPU with 1 CPU core.

**Purpose:**  
The CPU provides the processing power needed to run programs, commands, and services.

**Why It Is Important in Cloud Computing:**  
Compute resources are important because they allow applications and cloud services to process tasks and operate properly.

**Relation to KillerCoda:**  
The KillerCoda environment uses an Intel Xeon E312xx CPU with 1 CPU core to process the Linux system and the commands used in the terminal.

---

## 2. Storage Resources

**Example:** 19G disk with `/dev/vda1` mounted on `/`.

**Purpose:**  
Storage is used to save the operating system, files, applications, and other data.

**Why It Is Important in Cloud Computing:**  
Storage is important because cloud applications and services need a place to store and access their data.

**Relation to KillerCoda:**  
The KillerCoda environment provides a 19G disk, with `/dev/vda1` mounted on `/`, where the Linux system and files are stored.

---

## 3. Networking Resources

**Example:** IP addresses `172.30.1.2` and `172.17.0.1`.

**Purpose:**  
Networking allows computers, servers, and cloud services to communicate with each other.

**Why It Is Important in Cloud Computing:**  
Networking is important because it connects users, applications, and different cloud resources so they can exchange data.

**Relation to KillerCoda:**  
The KillerCoda environment has the IP addresses `172.30.1.2` and `172.17.0.1`, which provide network connectivity for the Linux environment.

---

## 4. Operating System

**Example:** Ubuntu 24.04.4 LTS.

**Purpose:**  
The operating system manages the server's hardware and software resources and provides an environment for running applications and commands.

**Why It Is Important in Cloud Computing:**  
An operating system is important because it manages cloud server resources and provides the platform needed to run applications and services.

**Relation to KillerCoda:**  
KillerCoda provides an Ubuntu 24.04.4 LTS environment where I can use the terminal, execute Linux commands, and investigate the server's resources.
