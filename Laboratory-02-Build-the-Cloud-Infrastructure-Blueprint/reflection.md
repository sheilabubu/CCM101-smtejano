# Mission Reflection

This laboratory activity helped me understand the basic components of cloud infrastructure and how they work together, I learned that compute provides the processing power needed to run applications, while storage is responsible for keeping files and data, and also how networking allows different resources to communicate with each other, while the operating system manages the resources and processes of the server. Using the KillerCoda Playground I was able to explore a Linux cloud environment and check important information such as the operating system, kernel version, CPU, RAM, disk capacity, mounted file systems, hostname, and IP address. I also gained more experience using Linux commands in KillerCoda to collect system information like `uname`, `lscpu`, `nproc`, `free`, `df`, `hostname`, and `hostname -I` helped me understand how to check different parts of a Linux system, but some of the commands were unfamiliar to me, but using them during the activity helped me become more comfortable with the Linux terminal. This gave me a better idea of how system administrators and cloud engineers can monitor and investigate a server environment. Another is where the laboratory involved researching and comparing AWS, Microsoft Azure, and Google Cloud Platform, I learned that these providers have different services and tools, they all provide similar core resources such as compute, storage, networking, and identity management, in this part of the laboratory helped me understand that choosing a cloud provider depends on the specific needs, technologies, and goals of an organization. Creating my laboratory outputs in GitHub helped me understand the importance of keeping technical work properly documented and organized and I was able to place my reports, screenshots, and other files in one repository, making them easier to access and review. So this laboratory improved my knowledge of cloud infrastructure and gave me more practical experience with Linux, cloud services, technical documentation, and GitHub and it also gave me more confidence to work with cloud computing tools and understand how cloud environments are designed and managed.
