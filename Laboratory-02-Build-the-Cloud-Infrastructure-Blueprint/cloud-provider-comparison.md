# Cloud Provider Comparison

## Comparison of Major Cloud Providers

| Infrastructure Component                 | AWS        | Microsoft Azure                 | Google Cloud Platform |
| ---------------------------------------- | ---------- | ------------------------------- | --------------------- |
| **Compute**                              | Amazon EC2 | Azure Virtual Machines          | Google Compute Engine |
| **Storage**                              | Amazon S3  | Azure Blob Storage              | Google Cloud Storage  |
| **Networking**                           | Amazon VPC | Azure Virtual Network           | Google Cloud VPC      |
| **Identity and Access Management (IAM)** | AWS IAM    | Microsoft Entra ID / Azure RBAC | Google Cloud IAM      |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

I think AWS is considered to offer the broadest range of cloud services among the three major cloud providers.Because it provides many different services for computing, storage, databases, networking, security, and other cloud needsa and because this is a wide selection of services and AWS can support different types of applications and workloads from small projects to large enterprise systems. So this make AWS a flexible choice for organizations with different cloud requirements.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would like to recommend Microsoft Azure for an organization that mainly use Microsoft products because Azure works closely with Microsoft services like Windows Server, Microsoft 365, and Active Directory. This integration can make it easier for the organization to manage the existing systems and users in the cloud. It can also reduce the difficulty of moving from a Microsoft-based environment to cloud services.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

I will choose Google Cloud because it have a widely recognized for strong capabilities in Artificial Intelligence, Machine Learning, and Kubernetes and it can provides various tools and services that can be used to develop, train, and deploy AI and ML applications. Also Google is also closely associated with Kubernetes because Kubernetes was originally developed at Google,  because of these technologies and services, Google Cloud is a strong platform for organizations working with AI, ML, and containerized applications.

### 4. What similarities did you observe among the three cloud providers?

With the three major cloud providers—AWS, Microsoft Azure, and Google Cloud—offer many similar core cloud services all of them provide computing resources, storage, networking, databases, and identity and access management and they also allow users to scale their resources depending on their needs and use cloud infrastructure without having to purchase and maintain all physical hardware themselves. Although the names and specific features of their services may be different, they provide similar solutions for common cloud computing requirements.
