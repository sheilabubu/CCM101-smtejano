# Cloud Platform Comparison

| Category           | AWS                                                                      | Microsoft Azure                                  | Google Cloud Platform                                   |
| ------------------ | ------------------------------------------------------------------------ | ------------------------------------------------ | ------------------------------------------------------- |
| Launch Year        | 2006                                                                     | 2010                                             | 2008                                                    |
| Compute Service    | Amazon EC2                                                               | Azure Virtual Machines                           | Google Compute Engine                                   |
| Storage Service    | Amazon S3                                                                | Azure Blob Storage                               | Google Cloud Storage                                    |

## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?

Among the three providers, **AWS has the widest selection of cloud services**. It offers services for computing, databases, storage, networking, security, analytics, artificial intelligence, and many other areas. Because of this extensive selection, AWS can support organizations with different types of technical and business requirements.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** provides the strongest integration with Microsoft technologies. Since Azure is developed by Microsoft, it works closely with products such as Windows Server, Microsoft 365, Microsoft Entra ID, and other Microsoft business solutions. This makes Azure a practical option for organizations already using Microsoft products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud** is particularly strong in Artificial Intelligence and Kubernetes. It provides various AI and machine learning services, while **Google Kubernetes Engine (GKE)** offers managed Kubernetes infrastructure. Google's experience in AI and container technologies makes its platform suitable for cloud-native and machine-learning workloads.

### 4. Which cloud platform would you personally choose and why?

I will choose **AWS** because its extensive collection of cloud services and flexibility. It also provides many options for computing, storage, networking, databases, security, and application development for someone learning cloud computing, AWS also provides opportunities to explore different areas of cloud technology using one platform.

## Cloud Service Equivalents

AWS, Microsoft Azure, and Google Cloud provide similar cloud services under different names. The table below shows the corresponding services for common cloud computing needs.

| Cloud Service               | AWS        | Microsoft Azure                | Google Cloud                   |
| --------------------------- | ---------- | ------------------------------ | ------------------------------ |
| Compute / Virtual Server    | Amazon EC2 | Azure Virtual Machines         | Compute Engine                 |
| Cloud Object Storage        | Amazon S3  | Azure Blob Storage             | Cloud Storage                  |
| User and Access Management  | AWS IAM    | Microsoft Entra ID             | Cloud IAM                      |
| Managed Relational Database | Amazon RDS | Azure SQL Database             | Cloud SQL                      |
| Managed Kubernetes          | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |
