# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP), commonly known as Google Cloud, is a collection of cloud computing services offered by Google. It provides organizations with access to computing resources, online storage, databases, networking tools, data processing, artificial intelligence, and software development services.

Through Google Cloud, businesses and developers can create, launch, and maintain applications using Google's cloud infrastructure instead of relying entirely on their own physical servers.

## 2. Global Infrastructure

Google Cloud has a worldwide infrastructure made up of **regions and zones**. These locations allow organizations to place their cloud resources in geographic areas that are suitable for their applications and users.

The global infrastructure helps businesses improve application performance, availability, and scalability. Google Cloud also provides network connectivity that reaches **more than 200 countries and territories**.

Organizations can choose specific regions and zones depending on factors such as user location, performance requirements, data regulations, and application design.

## 3. Cloud Management Console

The **Google Cloud Console** is a web-based platform used to access and control Google Cloud services. It gives users a central interface for managing their cloud environment.

Through the console, users can create virtual machines, configure networks, manage storage, deploy applications, monitor resources, and control user permissions. It also provides tools for viewing and organizing cloud projects and services.

## 4. Four Core Services

### Compute Engine

**Compute Engine** provides virtual machines that run on Google's cloud infrastructure. Users can configure these virtual machines according to the computing requirements of their applications.

### Cloud Storage

**Cloud Storage** is an object storage service used to save and retrieve data from the cloud. It can be used for files, backups, videos, images, application data, and other digital information.

### Cloud SQL

**Cloud SQL** is a managed relational database service. It allows organizations to operate databases in the cloud while Google manages many of the infrastructure and maintenance responsibilities.

### Virtual Private Cloud (VPC)

**Google Cloud VPC** provides a virtual networking environment for cloud resources. It allows organizations to control network connections, IP addresses, subnets, and communication between different cloud resources.

## 5. Three Advantages

1. **Advanced data processing** – Google Cloud provides powerful tools for processing, analyzing, and managing large amounts of data.

2. **Worldwide network** – Google operates a global network that allows applications and services to connect with users in different parts of the world.

3. **Powerful AI services** – Google Cloud provides technologies and services that help organizations develop and deploy artificial intelligence and machine learning solutions.

## 6. Typical Enterprise Use Cases

Organizations can use Google Cloud for:

* Hosting websites and web applications
* Running virtual machines
* Storing company data and backups
* Managing relational databases
* Data analytics and data processing
* Artificial intelligence and machine learning
* Developing and testing applications
* Running container-based applications
* Building applications for global users
* Managing large-scale cloud workloads
