# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing service offered by Amazon that provides organizations with on-demand access to computing resources and other IT services through the internet. It allows users to build, deploy, and manage applications without having to maintain all of the required physical hardware.

AWS offers a large collection of services, including computing, storage, databases, networking, security, analytics, and machine learning. It is widely used by businesses, government agencies, educational institutions, and startups.

## 2. Global Infrastructure

AWS has a worldwide cloud infrastructure consisting of **Regions and Availability Zones**. A Region represents a specific geographic area where AWS operates its infrastructure. Each Region contains multiple Availability Zones, which are separate and isolated locations designed to improve application reliability.

Businesses can select an AWS Region based on their users' locations, network latency, legal requirements, and the availability of specific services. AWS also offers infrastructure such as **Local Zones** and **Wavelength Zones** to support applications that need very low network latency.

## 3. Cloud Management Console

The **AWS Management Console** is a web-based platform that allows users to interact with AWS services. Through the console, users can create, configure, monitor, and manage cloud resources.

The console provides a centralized interface where users can access services, monitor resources, manage security settings, view account information, and check billing and usage.

## 4. Four Core Services

### Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides virtual computing resources in the cloud. It allows organizations to launch virtual servers and use them to run websites, applications, and business workloads.

### Amazon S3

**Amazon Simple Storage Service (S3)** is a cloud-based object storage service. It can store different types of data, including documents, images, videos, backups, and application files.

### Amazon RDS

**Amazon Relational Database Service (RDS)** is a managed service for relational databases. It simplifies tasks such as database setup, operation, maintenance, and scaling.

### Amazon VPC

**Amazon Virtual Private Cloud (VPC)** allows users to create a private and controlled network environment within AWS. It provides features for configuring subnets, IP addresses, routing, and network security.

## 5. Three Advantages

1. **Scalable resources** – AWS resources can be adjusted based on the changing needs of an organization.

2. **Global availability** – AWS provides cloud infrastructure in different geographic locations around the world, helping businesses serve users from different areas.

3. **Large service selection** – AWS provides numerous services for computing, storage, databases, networking, security, analytics, and other IT needs.

## 6. Typical Enterprise Use Cases

Enterprises commonly use AWS for:

* Website and application hosting
* Cloud-based database management
* File and data storage
* Backup and disaster recovery
* Software development and testing
* Enterprise application hosting
* Data analytics
* Artificial intelligence and machine learning
* Cloud migration
* Virtual server deployment
