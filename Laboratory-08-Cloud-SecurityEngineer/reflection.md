# Mission Reflection

Completing this Cloud Security mission helped me understand the importance of protecting a server through proper firewall configuration. A host-based firewall protects a server by controlling incoming and outgoing network traffic directly on the machine. Even if an attacker bypasses the physical network perimeter, the firewall can still block unauthorized connections to ports and services that are not allowed. Managing open network ports is also important because every active port can provide a possible entry point for attackers. If unnecessary ports remain open, attackers may discover vulnerable services and attempt to exploit them. By applying the Default Deny policy and allowing only the required connections, such as SSH for administration and port 8080 for the web application, I learned how to reduce the server's attack surface and limit unauthorized access. In a real enterprise environment, leaving a database port such as 3306 for MySQL open to the public internet is dangerous because attackers can directly target the database. They may attempt brute-force attacks, exploit software vulnerabilities, or gain access to sensitive information. Database access should be restricted to trusted application servers and authorized administrators instead of allowing connections from everyone.
This mission also changed my perspective on how easily a server can be compromised. Before completing the activity, I did not fully realize how important it was to configure a firewall before exposing an application to a network. I learned that even a working web application can be vulnerable if its network access is not properly controlled. Small configuration mistakes can create security risks, so checking ports and verifying firewall rules are essential steps. My GitHub portfolio is becoming more organized and professional as I complete eight cloud computing missions. It shows my progress in learning about cloud infrastructure, containers, system administration, and security. Documenting commands, screenshots, and reflections also helps me review what I have learned and demonstrate my practical skills. Overall, this mission taught me that server security requires careful configuration, regular monitoring, and continuous improvement rather than relying on a single security measure.
