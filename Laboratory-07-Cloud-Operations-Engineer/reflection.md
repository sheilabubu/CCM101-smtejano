# Mission Reflection

This laboratory helped me understand why monitoring is an important part of cloud computing. I learned that deploying an application is not enough because we also need to check the server's condition and make sure it can handle the application's needs. Checking the host server's resources is important even when containers are running properly because the server has limited CPU, RAM, and disk space. If these resources become full, the application may become slow or stop working. Using commands such as `free -h`, `df -h /`, and `top` helps identify possible problems before they affect users. If a user cannot log into a web application, I would use the `docker logs` command to check the application's recorded messages and errors. The logs might show problems with authentication, database connections, or other services. This information can help me investigate the cause instead of guessing what went wrong. Monitoring logs and metrics are different. Logs record specific events and requests, including errors such as the 404 response I generated during this activity. Metrics show numerical measurements, such as CPU percentage and memory usage, that help determine how well a container is performing. Both are useful for understanding and troubleshooting an application. Large companies can use tools such as Prometheus and Grafana to monitor thousands of containers. Prometheus collects and stores performance metrics, while Grafana displays the information in dashboards that make it easier to identify unusual activity. These tools help operations teams monitor many services in one place. My ability to troubleshoot Linux environments has improved because I gained experience using terminal commands, checking Docker containers, generating website requests, and examining application logs. I also learned how to monitor CPU and memory usage. This activity taught me to use actual system information to investigate problems instead of relying on guesses. I believe these skills will help me become more confident in handling cloud environments.
