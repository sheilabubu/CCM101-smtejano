# System Baseline Report

## Objective

The purpose of this activity is to check the server's RAM, disk storage, and CPU activity before deploying a web application.

## Importance of Disk Space Monitoring

Checking disk space before a massive traffic surge is important because the server needs enough storage for application data, temporary files, and logs to prevent service interruptions.
