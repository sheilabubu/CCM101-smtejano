# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focused on understanding cloud storage and deploying an object storage server using MinIO. I researched different types of cloud storage and used Docker to deploy MinIO as an S3-compatible object storage server. I also accessed the MinIO Web Console, created a bucket, and uploaded a sample file.

## Objectives

- Understand the differences between Block Storage, File Storage, and Object Storage.
- Identify common cloud storage use cases.
- Deploy a MinIO object storage server using Docker.
- Access the MinIO Web Console.
- Create and manage an object storage bucket.
- Upload a sample file to the created bucket.
- Document the technical steps used during the deployment.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- MinIO Web Console
- GitHub
- Web Browser

## Skills Learned

- Comparing different types of cloud storage.
- Deploying a storage server using Docker.
- Using Docker port mapping.
- Setting environment variables in a Docker container.
- Accessing a web-based storage management console.
- Creating and managing storage buckets.
- Uploading objects to an object storage server.
- Documenting cloud infrastructure deployment steps.
